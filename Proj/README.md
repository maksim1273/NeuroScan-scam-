#NeuroScan — лендинг для AI-радиолога

Учебный проект по кейсу «IT-стартап»: лендинговая страница для продвижения ИИ-ассистента врача-рентгенолога «NeuroScan: второе мнение для региональной медицины».

🎯 Цель проекта

Сбор качественных лидов (заявок на демо-доступ и презентацию) от главных врачей, заведующих отделениями и IT-директоров медицинских учреждений.

**Ключевое позиционирование:** ИИ не заменяет врача и не ставит диагноз. NeuroScan — инструмент «второго мнения», который ускоряет рутину, подсвечивает зоны риска и готовит черновик заключения.

✨ Что реализовано

- Hero-блок с ключевым сообщением, CTA и статистикой.
- Интерактивный слайдер «До / После»: сравнение обычного снимка и снимка с разметкой нейросети.
- Переключатель сегментов ЦА: «Госбольницы» / «Частные клиники».
- Блок «Боли и решения» — контраст «без / с NeuroScan».
- Табы «Как это работает» (3 шага).
- Блок доверия: точность, безопасность, ФЗ-152, РУ Росздравнадзора, дисклеймер.
- Калькулятор экономии и окупаемости для клиники.
- Блок социального доказательства (пример кейса).
- Лид-форма с валидацией и согласием на обработку персональных данных.
- Адаптивная вёрстка (мобильные, планшеты, десктоп).
- **Отправка заявок в Google Sheets** через Google Apps Script (без бэкенда).

🚀 Как запустить

1. Скачайте или склонируйте папку `neuroscan-landing`.
2. Откройте `index.html` двойным кликом в любом современном браузере.
3. Никакие сборщики, npm или серверы не нужны.

**Важно:** для работы отправки формы в Google Sheets нужно выполнить настройку (см. раздел «Отправка заявок в Google Sheets»).

📊 Отправка заявок в Google Sheets

Подробная инструкция — в отдельном разделе ниже. Кратко:

1. Создайте Google-таблицу с колонками: `Date`, `Name`, `Phone`, `Clinic`, `Email`.
2. Откройте **Расширения → Apps Script**, вставьте скрипт из инструкции, задеплойте как Web App.
3. Скопируйте URL веб-приложения и вставьте в `js/script.js` в переменную `GOOGLE_SHEET_WEBAPP_URL`.

После этого заявки будут автоматически появляться в таблице.

🛡 Безопасность и соответствие

- Работа с обезличенными данными.
- Соответствие ФЗ-152.
- Серверы на территории РФ.
- Передача по защищённому каналу (в демо-версии — HTTPS).
- Дисклеймер: ИИ не ставит диагноз, решение принимает врач.
